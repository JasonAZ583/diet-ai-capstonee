# Diet AI

DietAI is an AI-powered nutrition and meal-tracking application developed as a senior capstone project. The system combines a Swift-based user interface with a Python/FastAPI backend, SQLAlchemy database models, external nutrition data, and AI-generated meal recommendations
## Features
- Barcode food scanning
- Meal logging
- Macro tracking
- TDEE calculations
- Food inventory ("Vault")
- AI meal recommendations

## Tech Stack
- Frontend: Swift
- Backend: Python, FastAPI, Pydantic
- Database: SQLAlchemy, SQLite/MySQL
- External services: Open Food Facts and AI/LLM integration
- Collaboration: GitHub and Agile sprint planning
