# Diet AI

AI-powered nutrition and meal-tracking web application developed as a senior capstone project at Kean University.

## Features
- Barcode food scanning
- Meal logging
- Macro tracking
- TDEE calculations
- Food inventory ("Vault")
- AI meal recommendations

## Tech Stack
- Python
- FastAPI
- SQLAlchemy
- HTML/CSS
- OpenFoodFacts API
- GitHub
